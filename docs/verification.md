- 桌面消费者租约、取消、普通浏览器隔离。
- 归档会话和加载失败拒绝、主会话精确确认。
- 实际本机 HTTP、内部 RPC JSON 信封、页面认证适配、卸载清理。

独立仓库将包名统一为 `@stxr/dsh-session-bridge`，保留 v1 协议地址以兼容已有调用方。展示资源、包导出和根级 bundle 清单已校对；无第三方运行依赖或安装构建脚本。

## 真实桌面验证

开发阶段通过[换台](https://github.com/Stxr/huantai)的 Swift CLI 执行 `ht open`，DSH Client 确认另一条普通会话的历史已加载、主窗口 `mainView` 已选中目标，返回匹配的 `opened` 回执；本次切换约446毫秒，仅为实测记录。随后通过同一路径恢复测试前选择。

实际请求不存在的会话返回 `not-found` 且选择不变；缺少独立令牌返回401。发现目录为0700，记录为0600。停用插件后记录消失且专用路由返回404；重新启用后客户端就绪，并通过新一代插件收到真实调用方的确认。

换台接入侧的231项 Swift 测试通过，包含7项协议和 loopback HTTP 测试；这些测试由换台仓库维护，不是本仓库的运行依赖。
